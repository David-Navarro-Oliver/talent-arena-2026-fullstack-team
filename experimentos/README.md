# 🧪 Experimentos Técnicos

Esta carpeta está destinada a pruebas técnicas y pequeños proyectos creados a partir de aprendizajes obtenidos en Talent Arena 2026.

## 🎯 Objetivo

No solo documentar lo aprendido, sino aplicarlo.

Si detectamos una tecnología, práctica o enfoque relevante durante el evento, aquí desarrollaremos una prueba real.

## 📌 Qué debe contener cada experimento

Cada subcarpeta debe incluir:

- Un README explicando:
  - Qué problema aborda
  - Qué aprendimos del evento
  - Qué tecnologías usamos
  - Conclusiones técnicas

Ejemplo de estructura:

experiments/
└── nombre-del-experimento/
    ├── README.md
    └── código o demo

## 🚫 Qué NO va aquí

- Notas del evento (eso va en docs/)
- Imágenes (eso va en activos/)
- Ideas sin implementar
